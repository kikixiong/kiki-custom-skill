# Project manuscript bridge

Locate the active project from the task and read its instructions, manuscript,
run manifests and required scientific sources before describing current methods
or results. A literature skill does not define the project's scientific truth.

Use `--include-project` only when a configured project manuscript is needed for
comparison or revision. Do not count the manuscript as independent evidence for
its own claims. Distinguish supplied drafts from public external literature.

Check version-sensitive details against current code and frozen protocols:
view construction, negative sampling, supervision, objectives, training stages,
controllers, reconstruction targets, dataset splits and evaluation settings.
Resolve disagreements through authoritative project records; do not reconcile
different versions by inventing a combined method.

Project-specific constraints and unpublished research details belong in local
project records. Retrieve only the material needed for the writing task. This
skill does not launch experiments, rewrite results or select checkpoints.
