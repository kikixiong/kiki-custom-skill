# Core Section Checklists

## Abstract

- [ ] task, failure, gap, insight, method, evidence, and scope are covered
- [ ] each sentence has a unique function/information increment
- [ ] causal links are explicit and supported
- [ ] all major contribution classes appear
- [ ] method is an action/rationale, not a module list
- [ ] result detail is selective and credible
- [ ] claims and terms match the main text
- [ ] no generic importance, praise, or redundant ending

## Introduction

- [ ] opening altitude suits the audience and paper
- [ ] existing/default response is represented fairly
- [ ] gap and why-it-is-hard are distinct
- [ ] each paragraph has one main role
- [ ] adjacent paragraphs show real progression
- [ ] observation/figure creates a premise used by the method
- [ ] method preview includes rationale without derivation
- [ ] results preview matches evidence
- [ ] contributions are distinct and not newly introduced claims
- [ ] wording does not copy the Abstract

## Method

- [ ] execution trace exists before notation
- [ ] Preliminaries is minimal
- [ ] Overview maps components and dependencies
- [ ] symbols have types and one stable meaning
- [ ] symbols are introduced at first genuine need
- [ ] every formula has motivation and operational explanation
- [ ] one equation performs one logical action
- [ ] branch roles, shared state, fusion/update order, and output are explicit
- [ ] stopping, tie-breaking, and fallback are specified when defining behavior
- [ ] implementation-only settings and results are elsewhere
- [ ] Introduction, algorithm, framework figure, caption, and ablation align

## Figure Caption

- [ ] rendered asset has been inspected
- [ ] first sentence states purpose
- [ ] panels/stages and reading order are mapped
- [ ] setup, metric/statistic, and uncertainty are sufficient
- [ ] colors, markers, arrows, and symbols are explained
- [ ] observation is no stronger than the asset
- [ ] component names and symbols match the main text
- [ ] caption is locally self-contained without becoming a Results section
- [ ] final-scale text is legible and unclipped
