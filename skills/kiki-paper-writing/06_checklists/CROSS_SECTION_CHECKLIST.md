# Cross-Section Checklist

## Story

- [ ] one-sentence problem and gap are stable
- [ ] method directly answers the gap
- [ ] insight licenses method actions
- [ ] experiments test headline claims and components
- [ ] figures/tables reinforce the same story

## Terminology

- [ ] canonical term table exists
- [ ] method and component names match exactly
- [ ] task, failure, and metric terms do not drift
- [ ] abbreviations and hyphenation are consistent

## Claims

- [ ] proposition, strength, causality, and scope match across sections
- [ ] Abstract and Introduction do not exceed actual evidence
- [ ] Method describes intended behavior without guarantees
- [ ] Conclusion adds no stronger or new claim

## Method/notation

- [ ] one symbol has one meaning and type
- [ ] Intro summary matches Method dependencies
- [ ] algorithm and equations share execution order
- [ ] figure arrows, labels, and branch states match the main text
- [ ] ablations test stated component roles

## Evidence objects

- [ ] every figure/table is cited at its logical location
- [ ] captions, main text, and visual labels agree
- [ ] metrics, directions, numbers, and uncertainty match
- [ ] Abstract and Introduction wording differs despite conceptual alignment

## Version state

- [ ] canonical files are identified
- [ ] confirmed versus synchronized status is known
- [ ] no stale version was assembled
- [ ] important rejected alternatives remain recoverable
