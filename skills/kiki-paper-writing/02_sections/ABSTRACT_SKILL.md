# Abstract Skill

## Function

The Abstract is the paper story at maximum compression. It must answer what
problem matters, what exact gap remains, what insight/method addresses it, what
evidence exists, and what bounded contribution follows.

## Functional slots

Use slots, not a fixed sentence count:

1. task and value;
2. concrete failure;
3. missing criterion or gap;
4. evidence-backed insight;
5. method identity and core actions;
6. headline evidence;
7. bounded takeaway.

Merge adjacent slots when one sentence can carry both without ambiguity. Split
an overloaded slot when the main clause becomes unclear.

## From-zero algorithm

1. Fill each slot with one proposition.
2. Check every causal edge.
3. Replace implementation nouns with method actions and rationale.
4. Cover every major contribution class.
5. Add only the most decision-relevant evidence.
6. Calibrate verbs and scope.
7. Compress wording without deleting logic.

## Draft diagnosis

For each sentence label its function and information increment. Diagnose:

- no clear failure or gap;
- generic background consuming the budget;
- insight appearing without evidence;
- module list instead of method logic;
- result list without a headline finding;
- contribution absent or repeated;
- ending that praises instead of states a bounded takeaway.

Rebuild slots before line editing when two or more functions are missing.

## Compression procedure

1. Delete importance statements that add no consequence.
2. Replace lists with an umbrella term only if distinctions are not needed.
3. Merge setup with failure or method with rationale.
4. Remove examples and derivations.
5. Keep one strong result pattern; add a number only when it communicates
   magnitude or credibility better than prose.
6. Delete closing restatements.

Use the deletion test: what proposition is lost? If none, delete. If one useful
element is lost, replace with the smallest carrier.

## Claim audit

- Is the observation correlational or causal?
- Does `reliably`, `consistently`, or `generalizes` have defined scope?
- Does the evidence cover every task/model named?
- Does the Abstract claim exceed the Introduction or Results?
- Is novelty asserted instead of demonstrated by the gap/action pair?

## Terminology audit

Match title, method name, task, central failure, component names, metrics, and
claim scope with the active manuscript. Avoid introducing a synonym solely to
sound varied.

## Candidate selection

Compare by functional coverage, causal completeness, evidence calibration,
section fit, consistency, then concision and rhythm. Do not choose the most
compact version if it deletes the gap or rationale.

## Abstract-specific anti-patterns

- opening with broad field history;
- Abstract as chronological project report;
- component names without what they do;
- `We discover` without an evidence anchor;
- exhaustive benchmark/model/number inventory;
- final sentence that claims universal importance.

## Output

For revision, return the slot diagnosis, revised Abstract, semantic changes,
claim risks, and optional compressed alternative.
