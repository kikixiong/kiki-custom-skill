# Anti-Patterns

| Anti-pattern | Diagnostic symptom | Repair |
|---|---|---|
| Surface-first revision | synonyms change but logic does not | diagnose story and paragraph role first |
| Abstract as mini-Introduction | background, examples, and chronology dominate | keep conclusions and causal chain |
| Abstract as module list | method names appear without gap/rationale | express actions and why they address the gap |
| Introduction copy | repeats Abstract wording and resolution | expand mechanisms, evidence, and Figure logic |
| Related Work inventory | one citation per sentence, no comparison axis | group by capability and end with exact gap |
| Decorative example | example adds color but no inference | state what premise or distinction it proves |
| Sudden finding | `We find` has no evidence source | anchor it in an analysis, figure, or experiment |
| Connector camouflage | `therefore` bridges unrelated propositions | supply the missing warrant |
| Redundant ending | final clause renames the explanation | stop once the implication is complete |
| AI-style praise | `novel`, `powerful`, `remarkable` replaces content | state action, evidence, or measured consequence |
| Modifier stack | long noun phrase hides actor/action | restore subject and finite verb |
| Method as recipe | steps lack objective and rationale | state why each operation is needed |
| Notation theater | extra symbols create sophistication only | keep necessary objects and relations |
| Premature definition | Preliminaries forecasts every component | define symbols just in time |
| Model/object confusion | model, distribution, logit map, and output blur | type each object explicitly |
| Branch ambiguity | unclear shared history or number of trajectories | state shared/different state and update order |
| Table narration | prose reads cells in order | organize around research questions |
| Caption as label list | panels are named but not interpreted | state purpose, setup, and licensed observation |
| Caption as Results section | causes and implications exceed the asset | leave extended explanation in the main text |
| Rigid lint | fixed word/paragraph limits become universal laws | treat as venue- and function-dependent heuristics |
| Project overfitting | one method's stages become a global template | abstract to roles, dependencies, and evidence |

## Phrases worth inspecting, not blindly banning

Inspect `In recent years`, `It is worth noting`, `To alleviate this limitation`,
`extensive`, `significant`, `state of the art`, `obviously`, and `easy to see`.
Keep only when they carry a precise, supported function. Mechanical
find-and-replace can damage meaning.
