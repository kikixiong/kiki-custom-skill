# Workflow: From Zero

## 1. Build a story card

Collect only supported content:

```text
Task/value:
Concrete failure:
Existing/default response:
Exact gap:
Why difficult:
Evidence-backed insight:
Method actions:
Available evidence:
Scope/limitations:
Unknowns:
```

If the gap, insight, or evidence is missing, flag it rather than inventing it.

## 2. Build three ledgers

Create:

- claim → required evidence → actual evidence;
- concept → canonical term → definition;
- paragraph/section → unique function → handoff.

Use the ledgers as constraints for all later drafting.

## 3. Choose a writing order

Default:

1. story graph;
2. provisional Abstract;
3. Introduction map;
4. Method execution trace and notation;
5. experiment questions;
6. figures/tables and captions;
7. final Abstract and Conclusion.

If the method is not formalized, draft its execution trace before the Abstract.
If the main observation is uncertain, inspect the evidence figure first.

## 4. Draft by function

- Abstract: one sentence slot per story function.
- Introduction: one principal role per paragraph.
- Method: inputs → states → operations → outputs → rationale.
- Experiments: one research question per evidence block.
- Captions: purpose → map → setup → observation.

Do not optimize wording until each slot is logically valid.

## 5. Close the loop

After all sections exist:

- align promises with experiments;
- align Introduction method summary with Method Overview;
- align framework figure with execution order;
- update Abstract and Conclusion to match actual evidence;
- run claim, term, notation, reference, and rendered-asset audits.

## Deliverable

For an early draft, provide the story card, section/paragraph map, draft text,
known assumptions, and evidence gaps. Do not disguise missing results as prose.
