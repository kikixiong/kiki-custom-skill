# Workflow: From Outline or Template

## Diagnose before expansion

For every heading or bullet, record:

- intended narrative role;
- premise inherited from the previous item;
- new information;
- licensed conclusion;
- evidence or method dependency.

Then check:

- Does the order form a causal/inferential chain?
- Are two bullets performing the same job?
- Is a bridge missing between gap and insight or insight and method?
- Does detail appear before the concept that makes it relevant?
- Can the experiments validate the promises?

## Decide expansion versus restructuring

Expand directly only when the outline is logically complete. Otherwise:

1. preserve the user's content inventory;
2. propose a function-level reordering;
3. explain which dependency requires the change;
4. expand the repaired outline.

Do not treat template slots as mandatory if the paper lacks that content. Add a
new slot only for a real missing function.

## Expansion pass

1. Write topic/function sentences.
2. Add mechanism or evidence payload.
3. Add the strongest licensed conclusion.
4. Add a handoff only when the next paragraph depends on it.
5. Audit repeated information and section resolution.
6. Apply sentence-level style last.

## Output

Return the normalized outline, structural repairs, expanded text, and unresolved
scientific choices. Distinguish user-provided facts from inferred bridges.
