# Workflow: Compare Multiple Versions

## Align by function

Do not compare line numbers first. Align the units that perform the same role:
problem, gap, insight, method, result, transition, or contribution.

## Candidate sheet

For each candidate record:

| Dimension | Analysis |
|---|---|
| Main proposition | exact subject, action, object |
| Claim | strength, scope, causality |
| Information | added, removed, or implied |
| Logic | explicit warrant and referents |
| Local role | fit in sentence/paragraph/section |
| Context | repetition and handoff |
| Global effects | terms, symbols, later claims |
| Style | concision, naturalness, rhythm |

## Decide lexicographically

Use this order:

1. factual/evidential accuracy;
2. causal completeness;
3. narrative-role fit;
4. contribution/mechanism coverage;
5. global consistency;
6. concision and style.

A later advantage cannot compensate for an earlier failure.

## Hybrid rule

A hybrid is not automatically best. Reconstruct its main clause, scope,
referents, and paragraph function, then audit it as a new candidate.

## Output

State:

- selected candidate;
- decisive reason;
- failure of every rejected candidate;
- optional hybrid and its independent audit;
- downstream changes required.

Avoid fake numeric scores unless the user requests them; qualitative dimensions
are evidence for a decision, not a mechanical grading system.
