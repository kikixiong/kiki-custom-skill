# Task Map

## Writing

- General paper drafting: `af-scientific-writing`
- Systems venues: `af-systems-paper-writing`
- Chinese polishing or de-AI rewriting: `af-humanizer-zh`
- End-to-end polishing workflow: `af-paper-polish-workflow`

## Review

- Formal review report: `af-peer-review`
- Critique methods, evidence, bias, rigor: `af-scientific-critical-thinking`

## Submission

- Venue template and formatting: `af-venue-templates`
- Citations, BibTeX, DOI cleanup: `af-citation-management`

## Communication

- Publication figures: `af-academic-plotting`
- Markdown and Mermaid diagrams: `af-markdown-mermaid-writing`
- Slides and talks: `af-scientific-slides`, `af-presenting-conference-talks`

## Fallback

When none of the installed wrappers is a strong fit:

```bash
academicforge --json search "<topic>"
academicforge --json skills show <skill-id>
```
